# Vehicle Service Booking Frontend

React frontend for the vehicle service booking system, built with Vite.

## Live demo

[Open the deployed frontend](https://vehicle-service-booking-frontend-gold.vercel.app/)

## Requirements

- Node.js and npm

## Setup

```sh
npm install
```

Set `VITE_API_BASE_URL` in a local `.env` file to the backend API base URL. The default example is in `.env.example`.

## Development

```sh
npm run dev
```

## Production build

```sh
npm run build
```
